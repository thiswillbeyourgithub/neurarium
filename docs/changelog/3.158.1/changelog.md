# 3.158.1 (2026-10-30)

## Improved

- A section heading now reads as its title alone: the short description under it moved to the first line of the opened section, so the folded panel is less cluttered. (a2a60c5)
  fr: Le titre d'une section se lit désormais seul : la courte description qui l'accompagnait devient la première ligne de la section ouverte, pour un panneau replié moins chargé. (a2a60c5)

## Fixed

- Section titles in a detail panel can be selected and copied again; a click that ends a text selection no longer opens or closes the section. (47307bb)
  fr: Les titres de section d'un panneau de détail peuvent de nouveau être sélectionnés et copiés ; un clic qui termine une sélection de texte n'ouvre ni ne ferme plus la section. (47307bb)
