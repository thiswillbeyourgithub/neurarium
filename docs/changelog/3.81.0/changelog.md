# 3.81.0 (2026-09-10)

## Added

- The search box now finds the app's own controls, not only its data: About, the Legend, Sources & provenance, the keyboard shortcuts, What's new, the Data browser and the other browse sections, every view option, and the guided tour. A new "Controls" chip scopes the results to them, an option's row says whether it is on or off, and picking one does it.
  fr: La recherche trouve désormais les commandes de l'application, et plus seulement ses données : À propos, la Légende, Sources et provenance, les raccourcis clavier, les Nouveautés, le navigateur de données et les autres sections, chaque option d'affichage, ainsi que le tutoriel guidé. Une pastille « Réglages » y limite les résultats, la ligne d'une option indique si elle est activée, et la choisir l'exécute.
