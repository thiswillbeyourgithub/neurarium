# 3.46.0 (2026-08-10)

## Added
- Every drug now links to ClinPGx, the pharmacogenomics database: which gene variants change how you respond to it. The external links run EMA, FDA, ClinPGx, then Drugs.com (45e51d1)
  fr: Chaque médicament renvoie désormais vers ClinPGx, la base de pharmacogénomique : quels variants génétiques modifient la réponse au traitement. Les liens externes suivent l'ordre EMA, FDA, ClinPGx, puis Drugs.com (45e51d1)
- The Metabolism section gains a "Pathways" link: the rows below say which enzyme handles the drug, ClinPGx draws the whole route (45e51d1)
  fr: La section Métabolisme gagne un lien « Voies » : les lignes en dessous indiquent quelle enzyme prend en charge le médicament, ClinPGx en dessine le trajet complet (45e51d1)
- An enzyme's own panel links to its ClinPGx page, where the poor- versus ultra-rapid-metabolizer variants and the dosing guidance live (45e51d1)
  fr: La fiche d'une enzyme renvoie vers sa page ClinPGx, où se trouvent les variants métaboliseur lent ou ultra-rapide et les recommandations de posologie (45e51d1)

## Fixed
- The version number was missing from the panel header and the loading screen for the last two releases, and the "What's new" popup could not tell you anything had shipped (96e6c67)
  fr: Le numéro de version manquait dans l'en-tête du panneau et sur l'écran de chargement depuis deux versions, et la fenêtre « Nouveautés » ne pouvait donc rien vous annoncer (96e6c67)
