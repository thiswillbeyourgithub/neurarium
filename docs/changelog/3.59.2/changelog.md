# 3.59.2 (2026-09-03)

## Fixed

- In the data browser, a "relative amount per region" fact showed only which region came out on top, never by how much. It now carries the figure alongside, the same one the receptor and target panels show (4d6524f)
  fr: Dans l'explorateur de données, un fait « quantité relative par région » n'indiquait que la région arrivée en tête, jamais de combien. Il porte désormais le chiffre à côté, le même que celui affiché dans les fiches des récepteurs et des cibles (4d6524f)

## Improved

- Still in the data browser, kinds whose name already says everything (a circuit, a projection system) no longer show an empty second column: it disappears and the kind heads the name column (102279b)
  fr: Toujours dans l'explorateur de données, les types dont le nom dit déjà tout (un circuit, un système de projections) n'affichent plus une seconde colonne vide : elle disparaît et le type vient coiffer la colonne des noms (102279b)
