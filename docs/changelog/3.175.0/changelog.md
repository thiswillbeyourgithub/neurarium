## Added

- New effect: delusional parasitosis (Ekbom syndrome), which dopamine transporter inhibitors such as cocaine, methylphenidate and amphetamines can trigger, from a 2007 paper (0e07dfdd, d86c991d)
  fr: Nouvel effet : le délire de parasitose (syndrome d'Ekbom), que les inhibiteurs du transporteur de la dopamine (cocaïne, méthylphénidate, amphétamines) peuvent déclencher, d'après un article de 2007
- Activating the adenosine A2A receptor (regadenoson) is now linked to seizures, from a case report (d86c991d)
  fr: L'activation du récepteur A2A de l'adénosine (régadénoson) est désormais reliée aux convulsions, d'après un cas clinique
