# 3.25.0 (2026-07-26)

## Added
- "Found in" now answers how much, not only where: each region gets a bar showing the relative amount of that receptor, measured from human donor brains (db8efd5, 4dcd3c9)
  fr: La liste « Présent dans » ne dit plus seulement où, mais combien : chaque région reçoit une barre indiquant la quantité relative de ce récepteur, mesurée sur des cerveaux de donneurs humains
- Each profile says how many donors it rests on and how well they agreed; a gene whose donors disagreed publishes nothing rather than a shaky number (77694fb)
  fr: Chaque profil indique sur combien de donneurs il repose et à quel point ils concordent ; un gène dont les donneurs divergent ne publie rien plutôt qu'un chiffre fragile
