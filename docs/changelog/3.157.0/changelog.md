# 3.157.0 (2026-10-29)

## Added

- When a drug's section is empty but another stereo form of the same molecule fills it (Methylphenidate (D) has no French label checks, Methylphenidate (D,L) does), the empty section now links that form, opening it on the same section. (8a26706)
