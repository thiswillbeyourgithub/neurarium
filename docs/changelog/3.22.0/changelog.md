# 3.22.0 (2026-07-24)

## Added
- Active metabolites now have receptor actions of their own, so a receptor's page lists them beside the drugs, marked "metabolite of" (6b7d2b2, 8f95f64)
  fr: Les métabolites actifs ont désormais leurs propres actions sur les récepteurs : la fiche d'un récepteur les liste à côté des médicaments, avec la mention « métabolite de »
- Searching for a metabolite by name now finds it, and keeps the drug it comes from visible in the list (63b9134)
  fr: Chercher un métabolite par son nom le trouve désormais, en gardant visible le médicament dont il provient

## Fixed
- A metabolite made by two different drugs is now counted and listed once instead of twice (b2161a8, b3f4198)
  fr: Un métabolite produit par deux médicaments différents est désormais compté et affiché une seule fois au lieu de deux
