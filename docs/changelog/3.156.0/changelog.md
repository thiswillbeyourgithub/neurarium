# 3.156.0 (2026-10-28)

## Improved

- DrugsMap's axis captions end with "…" to show they list only the first few features, and each caption opens a dropdown listing every weight with a filter box, instead of a very long tooltip. (84fec39)
  fr: Les légendes d’axes de DrugsMap finissent par « … » pour montrer qu’elles ne citent que les premières variables, et chaque légende ouvre une liste déroulante de tous les poids avec un champ de filtre, au lieu d’une infobulle très longue. (84fec39)
- Hovering a DrugsMap dot whose name is already shown boldens that name in place instead of drawing it a second time elsewhere. (169558b)
  fr: Survoler un point de DrugsMap dont le nom est déjà affiché met ce nom en gras sur place au lieu de l’écrire une seconde fois ailleurs. (169558b)
- DrugsMap now starts with no normalization, in the default view and every preset. The picker lists None first, and "Shape" is renamed "Proportions". (bbb6e21)
  fr: DrugsMap démarre maintenant sans normalisation, dans la vue par défaut et dans chaque préréglage. Le sélecteur place « Aucune » en premier, et « Forme » devient « Proportions ». (bbb6e21)
