# 3.47.0 (2026-08-10)

## Added
- Receptors and other drug targets now link to ClinPGx, the pharmacogenomics database: which variants of the gene behind them change how a drug works on you (95fcafa)
  fr: Les récepteurs et les autres cibles médicamenteuses renvoient désormais vers ClinPGx, la base de pharmacogénomique : quels variants du gène correspondant modifient l'effet d'un médicament chez vous (95fcafa)

## Improved
- The gene and protein databases (ClinPGx, UniProt) are now searched by gene symbol rather than by the receptor's display name, so a receptor written with a Greek letter (α1A) actually lands on its entry (ADRA1A) instead of an empty result page (95fcafa)
  fr: Les bases de gènes et de protéines (ClinPGx, UniProt) sont désormais interrogées avec le symbole du gène plutôt qu'avec le nom affiché du récepteur : un récepteur noté avec une lettre grecque (α1A) atteint donc bien sa fiche (ADRA1A) au lieu d'une page de résultats vide (95fcafa)
