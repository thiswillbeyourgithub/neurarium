# 3.143.1 (2026-10-27)

## Improved

- The drug map is renamed the drugs map, and opens on currently marketed drugs only (untick it in Advanced to see every drug) (11da138, aaaf59f)
  fr: La carte des substances s’ouvre sur les seules substances commercialisées (à décocher dans Avancé pour toutes les voir) (11da138, aaaf59f)

## Fixed

- Drugs with identical binding profiles (the benzodiazepines) no longer pile into one illegible lump on the drugs map: they unfold into a spiral spaced a dot apart (87a1f14)
  fr: Les substances au profil de liaison identique (les benzodiazépines) ne s’empilent plus en un amas illisible sur la carte des substances : elles se déploient en spirale, espacées d’un point (87a1f14)
